# Kamchatka Track

Backend-платформа для расчета углеродного следа туристических маршрутов Камчатки. Проект объединяет Django-сайт, Telegram-бота на `aiogram 3.x`, общую PostgreSQL базу данных, справочники маршрутов и коэффициентов, а также единый сервис расчета.

## Архитектура

- `kamsite/` - настройки Django и маршрутизация проекта.
- `ecoapp/` - основное приложение с моделями, формами, API, админкой и шаблонами.
- `ecoapp/services/` - единый слой бизнес-логики:
  - `calculation.py` - расчет углеродного следа;
  - `recommendations.py` - подбор рекомендаций и чек-листов;
  - `reporting.py` - генерация итогового отчета;
  - `persistence.py` - сохранение результатов и совместимость со старыми моделями опросов.
- `ecoapp/bot/` - Telegram-бот на `aiogram`.
- `CO2/` - существующий фронтенд-калькулятор; его можно подключать к backend через API.
- `app.py` - точка входа для Telegram-бота.

## Основные сущности

- `Route` - 13 предустановленных маршрутов Камчатки.
- `TransportType` - типы транспорта и активностей.
- `FactorSet` и `EmissionFactor` - версии коэффициентов и сами коэффициенты.
- `Recommendation` и `Checklist` - персональные рекомендации и чек-листы.
- `CalculationResult` - итог каждого завершенного расчета.
- `SurveyTourist` и `SurveyLocal` - совместимый слой хранения анкет.

## Требования

- Python 3.10+
- PostgreSQL 14+
- Telegram bot token для запуска бота

## Установка и запуск локально

1. Создайте `.env` на основе `.env.example`.
2. Установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

3. Поднимите PostgreSQL и укажите его параметры в `.env`.
4. Выполните миграции и загрузите справочники:

```bash
python manage.py makemigrations
python manage.py migrate
python manage.py seed_reference_data
```

5. Запустите backend:

```bash
python manage.py runserver
```

6. Запустите Telegram-бота:

```bash
python app.py
```

## Docker

```bash
cp .env.example .env
docker-compose up --build
```

Сервисы:

- backend: `http://localhost:8000`
- PostgreSQL: `localhost:5432`
- bot: запускается отдельно, если передан реальный токен

Чтобы поднять bot вместе со стеком:

```bash
docker-compose --profile bot up --build
```

## API

- `GET /api/routes/` - список маршрутов.
- `GET /api/cities/` - список городов отправления.
- `GET /api/transport-types/` - список транспорта.
- `POST /api/calculate/tourist/` - расчет и сохранение анкеты туриста.
- `POST /api/calculate/local/` - расчет и сохранение анкеты местного жителя.
- `GET /api/results/<id>/` - получение сохраненного результата.

## Админка

Через Django admin можно управлять:

- маршрутами;
- коэффициентами и версиями коэффициентов;
- рекомендациями;
- чек-листами;
- результатами расчетов.

## Что уже работает

- единая доменная модель для сайта и бота;
- сохранение расчетов в общей БД;
- единый сервис расчета и рекомендаций;
- HTML-формы сайта с итоговым результатом;
- REST API для интеграции фронтенда;
- Telegram-бот через `app.py`;
- seed-команда для маршрутов, коэффициентов и рекомендаций;
- Docker-конфигурация для локального запуска.
